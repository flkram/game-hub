# 2048

## Summary

A sliding-tile puzzle on a 4 x 4 grid. Each move pushes every tile as far as it
can go in one direction, and two tiles with the same number that collide merge
into one tile of double the value. After every move a new tile appears in a
random empty cell, so the board slowly fills while you try to keep it tidy.

## How to Play

- **Arrow keys** — slide all tiles up, down, left, or right

There is no partial move: one keypress moves the entire board. A direction that
would change nothing is not a legal move.

## Objective

Create a tile with the value **2048**. Reaching it shows a win message, and you
can choose to keep playing for a higher tile. The game is lost when the grid is
full and no two neighbouring tiles match — at that point no move can change
anything.

## Notes

- The board starts as a 4 x 4 array of zeros with random tiles seeded in.
- Merging is scored: the value of each newly merged tile is added to the running
  score, so a single well-set-up move can be worth far more than several small
  ones.
- A tile that has just merged cannot merge again in the same move, which is what
  keeps a row of four identical tiles from collapsing into one.
- The game-over check scans every cell for an empty slot or a matching horizontal
  or vertical neighbour before declaring the board dead.

## Strategy

Keep your largest tile pinned in one corner and build a descending row toward it.
Avoid moves in the direction that would pull that tile away from its corner —
that single habit is most of the difference between stalling at 512 and reaching
2048.

## Implementation

`front_end/src/components/_2048.jsx` — a React component holding the board,
score, and win state in `useState`, with a `keydown` listener for input and
styling in `front_end/src/components/styles/_2048.css`.
